# Instructions for Maintaining the Repository 👨‍💻

These instructions are meant to help maintain the quality and consistency of the repository. Always follow these steps during your workflow:

1. **Always Lint Markdown Files:** 🚨
   - After making any modifications to markdown files, be sure to lint them to catch any errors or warnings.
   - Use the following command to lint markdown files:

     ```bash
     markdownlint README.md
     ```

2. **Use Conventional Commit Messages:** 📜
   - All commit messages must follow the [Conventional Commit](https://www.conventionalcommits.org) specification.
   - Use the structure:
     ```
     <type>(<scope>): <description>
     ```
     Examples:
     - `feat(setup): add installation script`
     - `fix(config): resolve issue with dotfiles`
     - `docs: update README for clarity`

3. **Commit Changes Thoughtfully:** ✔️
   - Double-check changes before committing them.

4. **Keep the Repository Organized:** 🗂️
   - Follow the existing structure for directories and files.

By maintaining these best practices, you'll ensure a smooth and error-free experience. 🚀
